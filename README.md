# WikiCartes

Un jeu de cartes à collectionner dont chaque carte est tirée d'un article de Wikipédia :
combats, mode histoire, duels, boutique de boosters et marché aux enchères entre joueurs.

**Jouer : https://capio98.github.io/wikicartes/** — sur ordinateur ou sur téléphone
(tenu droit ou couché), directement dans le navigateur.
